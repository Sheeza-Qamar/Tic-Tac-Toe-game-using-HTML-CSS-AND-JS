# ❌⭕ Tic Tac Toe Game

A classic **Tic Tac Toe game** built using **HTML, CSS, and Vanilla JavaScript**.  
The project focuses on clean UI, simple game logic, and responsive design.  
It is deployed on **Vercel** for fast and smooth performance.

🌐 **Live Demo:** https://your-vercel-link.vercel.app/

---

## ✨ Features

### 🎨 UI & Design
- Clean and minimal user interface
- Fully responsive layout (desktop & mobile)
- Interactive hover effects
- Simple and intuitive game board

### 🕹️ Gameplay
- Two-player mode (Player **X** vs Player **O**)
- Automatic win detection
- Draw detection
- Displays current player turn
- Restart game functionality

### ⚡ Performance
- Lightweight and fast
- No external libraries or frameworks
- Pure Vanilla JavaScript
- Cross-browser compatible

---

## 🛠️ Tech Stack

- **HTML5** – Structure of the game
- **CSS3** – Styling and layout
- **JavaScript (Vanilla JS)** – Game logic and DOM manipulation
- **Vercel** – Deployment and hosting
